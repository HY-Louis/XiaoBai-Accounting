## ✨ 新功能

- **窗口自适应放大**：把窗口拉大或最大化时，整个界面会等比例放大，不再是"中间一小条、两边全空白"
- **本月支出日历**：窗口够宽时，右侧自动出现一张日历热力图——花钱越多的日子颜色越深，鼠标悬停可看当天金额；窗口拉窄时自动隐藏，主界面不受影响
- **氛围背景**：两侧空白换成柔和渐变和缓慢漂移的光斑，不再是一片死灰

## 🐛 重要修复

- **修复 v1.1.0 无法打开、或点"保存"提示"保存失败，请重试"的问题**（原因是一个依赖库与 Electron 22 不兼容）。如果你装的是 v1.1.0，直接安装本版本覆盖即可。

## 📥 安装

- **Windows**：下载 `.exe`，双击安装。首次运行如遇蓝色"未知发布者"提示，点 **"更多信息" → "仍要运行"** 即可
- **Mac**：下载 `.dmg`，打开后拖入"应用程序"文件夹
