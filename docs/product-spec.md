# 小白记账 — 产品需求文档

## 1. 产品定位

### 1.1 产品简介
小白记账是一款运行在 Windows 和 Mac 电脑上的个人记账工具。专为不熟悉财务管理的普通用户设计，帮助用户轻松记录每一笔日常花销，了解"钱花在哪了"。

### 1.2 目标用户
- 想开始记账但觉得太麻烦的普通人
- 对手机记账 App 有抵触，更喜欢在电脑上操作的用户
- 不需要复杂财务功能，只需要简单记录支出的用户

### 1.3 核心价值
- **极简操作**：打开即记，3 步完成一笔记录（输入金额 → 选分类 → 保存）
- **本地存储**：数据完全保存在用户电脑上，不上传任何服务器，隐私安全
- **一目了然**：通过图表直观了解消费结构和趋势

## 2. 功能清单

### 2.1 V1.0 版本（本次开发）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 添加支出 | 输入金额、选择两级分类、添加备注（可选）、选择日期 | P0 必须 |
| 账单列表 | 按时间倒序展示所有支出，支持按分类和月份筛选 | P0 必须 |
| 删除支出 | 删除某条记录（软删除，支持撤销） | P0 必须 |
| 支出统计 | 饼图（按大类分布）+ 柱状图（每日趋势），可选月份 | P0 必须 |
| 分类管理 | 用户可新增/修改/删除分类 | P1 重要 |
| 本月总支出 | 首页顶部醒目显示当月累计支出 | P1 重要 |

### 2.2 后续版本（不包含在本次开发）

| 功能 | 描述 |
|------|------|
| 收入记录 | 记录收入来源和金额 |
| 预算设置 | 为分类设置月度预算，超支提醒 |
| 数据导出 | 导出为 CSV/Excel 文件 |
| 数据备份恢复 | 手动备份到文件，从文件恢复 |
| 多账本 | 支持创建多个独立账本（如家庭账本、旅行账本） |

### 4.2 分类管理规则
- 用户可新增自定义分类和子类
- 用户可修改分类名称和图标
- 删除分类时，如该分类下已有支出记录，提示用户将记录迁移到其他分类
- 系统预设分类不可删除，但可修改

## 5. 数据模型

### 5.1 支出记录 (Expense)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | 字符串(UUID) | 唯一标识 |
| amount | 整数 | 金额，单位：**分**（如 1250 = ¥12.50） |
| categoryId | 字符串 | 一级分类ID，如 "food" |
| subcategoryId | 字符串 | 二级分类ID，如 "food-breakfast" |
| note | 字符串(可选) | 备注说明 |
| expenseDate | 字符串 | 支出日期，格式：YYYY-MM-DD |
| createdAt | 字符串 | 记录创建时间，ISO 8601 |
| updatedAt | 字符串 | 最后更新时间，ISO 8601 |
| deletedAt | 字符串(可选) | 软删除标记，非空表示已删除 |

### 5.2 分类 (Category)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | 字符串 | 唯一标识，如 "food", "food-breakfast" |
| name | 字符串 | 分类名称，如 "餐饮饮食", "早餐" |
| icon | 字符串 | 图标(emoji)，如 "🍽️", "🥣" |
| parentId | 字符串(可选) | 父分类ID，一级分类为空 |
| sortOrder | 整数 | 排序序号 |
| isDefault | 布尔 | 是否为系统预设分类 |
| createdAt | 字符串 | 创建时间 |
| updatedAt | 字符串 | 更新时间 |
| deletedAt | 字符串(可选) | 软删除标记 |

## 6. 交互规范

### 6.1 金额输入
- 支持小数点后两位
- 自动过滤非数字字符
- 显示时格式化为 ¥1,234.56

### 6.2 反馈机制
- 保存成功：底部弹出绿色提示"保存成功"
- 删除记录：弹出确认对话框"确定要删除这条记录吗？"
- 操作失败：底部弹出红色提示，说明原因

### 6.3 空状态
- 账单列表为空时：显示"还没有记账记录，去记一笔吧～" + 跳转按钮
- 统计数据为空时：显示"本月暂无支出数据"

## 7. 非功能需求

| 需求 | 说明 |
|------|------|
| 性能 | 列表滚动流畅，1000条记录不卡顿 |
| 数据安全 | 数据仅存储在本地，不上传任何服务器 |
| 界面 | 支持浅色/深色主题（优先实现浅色） |
| 语言 | 界面文字全部使用简体中文 |
| 货币 | 仅支持人民币(CNY)，符号 ¥ |
